# 🏨 Hotel Reservation System

A console-based Hotel Reservation System developed using **Java, JDBC, and MySQL**
following **DAO–DTO architecture**.

---

## 🚀 Features

- Room availability check
- Book room
- Cancel booking
- View bill
- Date-based SQL queries
- Foreign key constraints
- Clean DAO architecture

---

## 🛠️ Technologies Used

- Java (JDK 8+)
- JDBC
- MySQL
- Git & GitHub

## 🗄️ Database Schema

Tables:

- bookings

---

## ▶️ How to Run

1. Install Java JDK  
2. Install MySQL Server  
3. Create database using SQL file  
4. Add MySQL Connector JAR  
5. Run `HotelMain.java`
